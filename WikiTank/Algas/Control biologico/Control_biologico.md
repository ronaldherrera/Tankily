## Control biológico — quién come qué

### Comedores de algas en agua dulce

| Organismo | Algas que come | Notas |
|---|---|---|
| **Otocinclus affinis** | Diatomeas ★★★★★, GDA ★★★★, GSA ★★★, GHA ★★ | Mejor para cristal y hojas. Muy delicado en adaptación. |
| **Ancistrus sp. (Busca-plecos)** | GHA ★★★★, Cladophora ★★★, GDA ★★★ | Cueva necesaria. Raspa madera también. |
| **Crossocheilus oblongus (SAE real)** | BBA ★★★★★, Staghorn ★★★★, GHA ★★★ | El único que come BBA vivo. Comprar el real (no el falso). |
| **Gyrinocheilus aymonieri (SAE chino)** | Diatomeas ★★★, GDA ★★★ | Se vuelve agresivo de adulto. Evitar en acuarios de comunidad. |
| **Caridina multidentata (Amano)** | GHA ★★★★★, Staghorn ★★★, BBA muerto ★★★★ | Mejor gamba comedora de algas. Necesita mínimo 6. |
| **Neocaridina davidi (Cherry)** | Diatomeas ★★★★, algas blandas ★★★ | Menos efectiva que Amano pero más fácil. |
| **Neritina natalensis** | GSA ★★★★★, GDA ★★★★, diatomeas ★★★★ | La mejor para GSA y GDA. No se reproduce en agua dulce. |
| **Melanoides tuberculata** | Ciano (excavando) ★★★, detritos ★★★★ | Remueve sustrato. Se reproduce rápido. |
| **Jordanella floridae (Florida Flag)** | BBA ★★★★, GHA ★★★ | Efectivo pero semiagrresivo. |
| **Molly (Poecilia sp.)** | GHA fina ★★★, ciano blanda ★★ | Necesita sal leve. Fácil. |

### Comedores de algas en agua marina

| Organismo | Algas que come | Notas |
|---|---|---|
| **Zebrasoma flavescens (cirujano amarillo)** | GHA ★★★★★, turf ★★★★, Bryopsis ★★★ | El más popular. Necesita min. 200L. |
| **Ctenochaetus strigosus (kole tang)** | Diatomeas ★★★★★, ciano ★★★★, detritos ★★★★ | Especialista en algas cortas y ciano. |
| **Zebrasoma xanthurum (cirujano púrpura)** | GHA ★★★★, turf ★★★★ | Agresivo con otros tangs. |
| **Siganus vulpinus (Foxface)** | Bryopsis ★★★★★, GHA ★★★★, Caulerpa ★★★★ | Muy eficaz. Espinas venenosas. |
| **Mithraculus sculptus (cangrejo esmeralda)** | Valonia ★★★★★, GHA ★★★ | Puede atacar corales pequeños. |
| **Turbo fluctuosa (caracol turbo)** | Turf ★★★★, GHA ★★★, Coralline limpieza ★★★★ | Gran apetito pero puede volcar corales. |
| **Diadema antillarum (erizo)** | Turf ★★★★★, Cladophora ★★★★ | Muy efectivo pero espinas peligrosas y puede dañar corales. |
| **Tripneustes gratilla (erizo)** | GHA ★★★★, turf ★★★ | Más seguro que Diadema. |
| **Elysia crispata / E. ornata** | Bryopsis ★★★★★ | Nudibranquio especialista. Difícil de mantener. |
| **Hermit crabs (ermitaños)** | Diatomeas ★★★★, ciano ★★★, GHA ★★ | Variedad de especies. Limpian superficies. |
